# Как получить APK Dessert Lab только с телефона

Эта версия подготовлена для облачной сборки через GitHub Actions. Android Studio, Android SDK и Gradle на телефоне устанавливать не нужно: они будут установлены на облачном runner GitHub.

## Что понадобится
- аккаунт GitHub;
- браузер на Android;
- архив проекта, распакованный в корень репозитория (в корне должны быть `settings.gradle.kts`, `build.gradle.kts`, папка `app` и папка `.github`).

## Сборка
1. Создайте на GitHub новый **пустой** репозиторий, например `dessert-lab-android`.
2. Загрузите в него содержимое этой папки проекта, а не ZIP-архив как один файл. Сохраните структуру папок.
3. После первого коммита откройте вкладку **Actions** репозитория.
4. Выберите workflow **Build Dessert Lab APK** и нажмите **Run workflow**. Также сборка запускается автоматически после отправки изменений в ветку `main` или `master`.
5. Дождитесь зелёного статуса **Success**. Откройте завершённый запуск, прокрутите до **Artifacts** и скачайте `Dessert-Lab-1.2.1-debug-apk`.
6. Распакуйте скачанный архив на телефоне. Внутри будет `app-debug.apk`. Откройте файл и разрешите установку приложений из используемого источника, если Android попросит.

## Если GitHub не показывает Actions
- Убедитесь, что файл `.github/workflows/android-apk.yml` находится именно в корне репозитория.
- Убедитесь, что проект загружен с сохранением папок, а не одним ZIP-файлом.
- Проверьте, что Actions разрешены в настройках репозитория.

## Важно
- Это debug APK для установки и тестирования, не подписанный релиз для Google Play.
- Сборка ещё не считается проверкой приложения на реальном устройстве. После установки нужно проверить запуск, сохранение рецептов, импорт и экспорт JSON.
- Не публикуйте в репозитории пароли, ключи подписи или личные резервные копии рецептов.
