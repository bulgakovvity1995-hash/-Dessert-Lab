# Dessert Lab Android 1.2.1

Первая Android-оболочка, подключающая актуальную рабочую веб-версию Dessert Lab 1.2 без потери её функций.

## Функции, перенесённые в Android
- создание, редактирование, поиск и удаление технологических карт;
- ингредиенты, количества, закупочные цены и расчёт себестоимости;
- пересчёт по количеству порций;
- геометрический пересчёт круглой формы по диаметру, высоте и количеству одинаковых колец;
- печать техкарты через системные возможности WebView;
- локальное хранение рецептов на устройстве;
- импорт JSON-резервной копии;
- экспорт JSON через системный диалог сохранения Android;
- копирование пересчитанной рецептуры в буфер обмена Android.

## Требования
- Android Studio (рекомендуется актуальная стабильная версия)
- Android SDK 35
- JDK 17 или новее

## Сборка APK
Откройте эту папку в Android Studio, дождитесь Gradle Sync, затем выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
Debug APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Важные ограничения текущего этапа
- Это локальное приложение без аккаунтов и облачной синхронизации.
- Геометрический калькулятор рассчитан на одинаковые круглые кольца; разные формы/размеры в одной закладке — отдельное улучшение.
- Составные десерты, библиотека ингредиентов как отдельный справочник и расширенные технологические этапы пока не реализованы.
- Для выпуска APK необходима реальная сборка Android Studio/Gradle и проверка на устройстве. Исходный код сам по себе не является готовым APK.

## Облачная сборка APK с телефона
В репозитории добавлен workflow GitHub Actions: `.github/workflows/android-apk.yml`. Он устанавливает JDK 17, Android SDK 35 и Gradle 8.9 на облачном runner, затем выполняет `assembleDebug` и сохраняет APK как артефакт на 14 дней.

Пошаговая инструкция для Android находится в `PHONE_BUILD_GUIDE_RU.md`.
